# Similar project => Our project: AI Financial Assistant

Build a personal finance chatbot
Start with recording one expense, then gradually add financial features.

The learning roadmap

1. Record one expense — “I spent $15 on food.”
2. Understand the message — extract amount, category, and description.
3. Store expenses — save records in a database.
4. Calculate totals — “How much did I spend this month?”
5. Track income and budgets — compare income, expenses, and limits.
6. Add AI capabilities — handle varied wording, clarify ambiguity, and answer questions using verified financial data.
7. Build the full application — authentication, a dashboard, APIs, security, and deployment.
